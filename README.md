# 默書探險隊 · 小三中文第二單元

嶺南大學香港同學會小學　中文科　三年級上學期　第二單元「默書溫習重點」
默書日期：11 月 6 日

一個單頁互動溫習網頁，四關遊戲＋星星獎勵，適合小三學生自己練，也適合家長陪讀。

合共 24 粒星。全對得金牌，18 粒以上銀牌，其餘銅牌；成績頁會列出「仲要留意」的詞語，一按「錯題重練」即跳去未做對的關卡。

### 寫字練習（默書必備）

因為默書要寫得出，所以第五關係手寫訓練：

- **田字格描紅**：範字以淺灰印在格內，用手指或觸控筆照住寫。
- **默寫模式**：一按「蓋住範字」即可遮住範字，只靠讀音自己寫（字位改用 1、2、3 表示，唔會穿橋）。
- **自動評分 0–10 分**：把字跡同範字做像素比對，計「覆蓋率」（範字的筆畫有幾多寫到）同「準確度」（寫出去嘅墨有幾多落喺字內），
  `分數 = 10 ×（覆蓋率 × 0.62 ＋ 準確度 × 0.38）`；寫得太粗或太亂會封頂，太少筆畫亦會壓分。
- 7 分以上當過關，8 分以上自動跳去下一個字；每個字的分數會記住，最好成績為準。全部字過關，該詞語就會亮起綠燈。

## 使用

- 直接開 `index.html`，或上 GitHub Pages。
- iPhone：Safari 開啟 → 分享 → 「加入主畫面」，即可全螢幕當 app 用。
- 進度（星星、寫字分數）存在瀏覽器 `localStorage`（key: `p3u2_v1`），同一部機再開會記得；按「重新開始」可清空。
- 寫字用 Pointer Events，支援手指、Apple Pencil；畫布已設 `touch-action:none`，寫字時唔會拖動頁面。
- 讀音／課文朗讀用瀏覽器內建語音（zh-HK），iOS 的粵語語音支援視乎系統版本。

## 技術

單一 `index.html`，無外部依賴、無需 build。CSS 手寫，音效用 Web Audio 即時合成，答對有紙碎動畫。

## 修改內容

詞語、填充句、課文、成語都放在 `index.html` 開頭 `<script>` 內的 `WORDS`、`FILL`、`PASSAGE_TOKENS`、`PASSAGE_ANSWERS`、`IDIOMS`、`QUIZ` 幾個陣列，直接改文字即可；改動字數時記得同步 `PASSAGE_BANK`。

寫字練習唔需要額外字庫：範字同評分基準都係即時用系統楷體（`Kaiti SC / Kaiti TC / STKaiti / DFKai-SB / KaiTi`，再退回宋體、明體）畫出嚟，所以改成任何詞語都自動有田字格同評分。
